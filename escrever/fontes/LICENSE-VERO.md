# VERO — Verificador Ortográfico Livre 3.2

O arquivo `dicionario.js` na raiz deste aplicativo contém, em forma
comprimida, os radicais e as regras de afixo do VERO.

```
VERO - Verificador Ortográfico Livre - Versão 3.2
Copyright (C) 2006 - 2013  por Raimundo Santos Moura
<raimundo.smoura@gmail.com>
Brasil - outubro 2013

Este é um dicionário para correção ortográfica da língua Portuguesa
para o Hunspell.

Este programa é livre e pode ser redistribuído e/ou modificado nos
termos da Licença Pública Geral Menor versão 3 (LGPLv3), como publicado
pela Free Software Foundation, e pela Mozilla Public License, como
publicado pela Mozilla Foundation.
```

Nada do dicionário foi alterado: o empacotamento apenas reescreve as
mesmas regras e os mesmos radicais num formato que o navegador lê.
